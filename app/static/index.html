Что показывает эксперимент

Text-only использует только транскрипцию. Audio-only использует MFCC признаки. Attention Fusion объединяет обе модальности через Multi-Head Attention.

Основные метрики: Accuracy и Macro-F1. Если fusion показывает лучший результат, мультимодальное объединение оказалось полезным для этой задачи.
